# 🔐 Password Manager (PySide6)

Безопасный менеджер паролей с графическим интерфейсом, реализованный на Python с использованием PySide6. Проект создан в учебных целях для отработки навыков построения архитектуры приложений, работы с криптографией и Qt-фреймворком.

---

## 📌 Возможности

- **Регистрация и аутентификация** по мастер-паролю.
- **Гибридная криптосхема**:
  - Данные шифруются симметричным алгоритмом **AES-256-GCM**.
  - Симметричный ключ шифруется асимметричным **RSA-2048**.
- **Локальное хранение** — все данные сохраняются в SQLite-базе.
- **Генератор паролей** с проверкой сложности (буквы разных регистров, цифры, спецсимволы).
- **Импорт и экспорт в CSV** — удобно переносить записи из браузеров или делать резервные копии.
- **Поиск** по всем полям записей (название, сервис, логин, почта, пароль).
- **Кэширование ключа** через системную связку (`keyring`) — пароль не запрашивается при каждом действии.
- **Автоматический выход** по таймауту (опционально, настраивается в коде).
- **Удаление и редактирование** записей через контекстное меню.

## 🖥️Использование

- Главное окно содержит таблицу со всеми записями, поле поиска и кнопки управления.

- Кнопка «+» — добавление новой записи. Пароль можно сгенерировать автоматически.

- Кнопки «↑» и «↓» — экспорт и импорт CSV.

- Двойной клик по записи — редактирование.

- Правый клик — вызов контекстного меню (редактировать / удалить).

- Поиск работает в реальном времени по всем полям.
